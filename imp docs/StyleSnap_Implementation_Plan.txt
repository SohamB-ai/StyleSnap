1. How to Use This Plan
This document is the single source of truth for building StyleSnap across all three versions. Every task includes a doc reference (which document to consult), the exact file or module to create, and an estimated hour count. Tasks are ordered by dependency — do them top-to-bottom within each week.

3. Version 1 — Core Parity  (Weeks 1–3)
Goal: A solid, accurate, free extension that matches everything both reference extensions offer. Ship to Chrome Web Store by end of Week 3. V1 is the foundation all future versions build on — accuracy here matters more than speed.
V1 Deliverable
Definition of Done
Token extraction
Colors/typography/spacing/shadows/radii/breakpoints extracted with ≥95% accuracy on 10 test sites
Element inspector
Hover → highlight → click → CSS + HTML in panel. Works on 10 test sites.
Asset finder
All images/SVGs/icons listed. ZIP download works. Favicon always included.
Export formats
DESIGN.md, tokens.json (W3C DTCG), tailwind.config.js — all download correctly.
History
Last 10 extractions saved. Load + delete work. Auto-eviction fires on entry 11.
CWS listing
Extension live on Chrome Web Store with description, screenshots, privacy policy.

4. Version 2 — Upgraded Accuracy & Depth  (Weeks 4–10)
Goal: Introduce features that neither competitor has — layout extraction, component detection, AI prompt engine, and screenshot pipeline. V2 is the version that makes StyleSnap a genuinely differentiated product.
V2 Deliverable
Definition of Done
Screenshot pipeline
Full-page PNG + section screenshots captured and downloadable for any typical webpage.
Layout extraction
Section breakdown with grid/flex info for any of the 10 reference sites.
Component detection
≥10 components detected with ≥90% label accuracy on component-heavy sites (e.g., stripe.com).
AI prompt engine
5 tool-specific master prompts generated. Developer can paste Cursor prompt into Cursor and get correct UI.
Edge case handling
Tailwind-heavy, CSS-in-JS, and CSS-variable sites all extract with ≥97% accuracy.
CWS update
V2 published as an update to the existing CWS listing.
